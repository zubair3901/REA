# Roomform interface redesign

This release replaces the sidebar-led presentation with an editorial, responsive
website and a shared visual system for buyer, seller and professional pages.

- Self-hosted Manrope typography and Cormorant Garamond italic accents, with
  included SIL Open Font License notices. Larger form controls and readable text.
- Photography-led landing page, keyboard/touch comparison slider, selectable
  project direction, one primary redesign action and a dedicated consultation CTA.
- Studio sequence: room photo → budget and new/pre-loved preference → style and
  generation → real-product selection, estimate and consultation/order request.
  A budget slider supplements the precise number input. Settings collapse after
  generation and can be reopened to refine the project.
- Larger result canvas, expandable image view, clickable SKU markers, original
  seller photography, region selection and existing item-replacement integration.
- Seller pages separate account creation, photo-first listing preparation,
  inventory/stock management and orders into clear sections and tabs.
- Responsive navigation, keyboard focus states, Escape dismissal and reduced
  motion support. Application features retain their authentication requirements.

The before/after hero is an illustrative comparison: the empty room was created
with an image-editing tool from the credited inspiration photograph. It is not a
live customer result or a claim of tested product fidelity. Real catalog data is
not fabricated to fill the interface. The seller-photo browser test uses a real
photographic fixture, not live vendor stock. AI/payment availability remains
subject to the backend configuration described in the release documentation.
