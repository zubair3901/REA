# Local fonts

Manrope (400–800) and Cormorant Garamond Italic (400) are served locally so the
interface does not depend on a third-party font request. Both use the SIL Open
Font License; the original notices are included here.

Sources: https://fonts.google.com/specimen/Manrope and
https://fonts.google.com/specimen/Cormorant+Garamond
